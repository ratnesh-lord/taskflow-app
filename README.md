# TaskFlow

A personal productivity app: tasks, reminders, projects, recurring work and home-screen widgets on Android, with a web view of the same data and cloud sync through Supabase.

Status: Phase 1 (architecture) is complete. Phase 2 (database and sign-in) is in progress on the `phase-2` branch.
